# Update checker (v0.5.0): verification checklist

Branch `v0.5`, version 0.5.0. Checks: typecheck clean, 712 TypeScript tests, 381 C++ tests, and build / build:site / dist all pass. `release/latest.yml` names `lolPing-Setup-0.5.0.exe` with a sha512, and the blockmap exists.

## Verified

**Unit tests**
- Version comparison.
- The schedule: 10 s, then 6 h, as a chain that never overlaps or piles up.
- Notify-once, including across a restart.
- Every state transition and interleaving: check during download, stop during check or download, a late old download, retries.
- MacBackend:
  - GitHub JSON validation;
  - the 15 s timeout;
  - digest required and must match;
  - `.part` cleanup and abort;
  - an unwritable Downloads folder;
  - the order focus → dialog → open → quit.
- WinBackend:
  - auto-download off;
  - the 30 s check timeout;
  - progress;
  - cancellation;
  - the 1.5 s restarting toast before `quitAndInstall(true, true)`;
  - skipping the install when lolPing is already quitting.
- Short error text: the first line only, at most 150 characters.
- Tray results are toasted for tray-started checks and updates.
- The settings window can't overwrite `updateNotifiedVersion`.

**Packaging**
- electron-updater is bundled into `out/main`.
- `app-update.yml` names github / darrenprx / lolPing.
- The release workflow creates a draft, the Windows job uploads the exe, `latest.yml` and the blockmap, the Mac job uploads the DMG, and a last job publishes.

**Dev app** (local test server announcing 9.9.9)
- The tray item and the About card states appear.
- The toast shows once, and not again after a restart.
- The error card appears with Retry.
- Chinese text is used throughout.

**Real Windows update on your PC** (0.5.0 test build updating to 0.5.1 from a local server)
- The install is silent: no installer window and no admin prompt.
- "Restarting to update…" is seen for about 1.6 s.
- lolPing relaunches by itself on 0.5.1 in about 15 s.
- `settings.json` is byte-identical afterwards.
- The launch-at-startup Run key is kept.
- The room is rejoined.
- A custom install folder is updated in place.
- End state:
  - **Installed:** test build 0.5.1 in your usual folder, with your settings restored.
  - **New shortcut:** the installer added `Desktop\lolPing.lnk`.

## Known and accepted

- v0.4 and older users update by hand once.
- The Mac can't replace itself, because Squirrel.Mac needs a paid signature.
- After an update the settings window opens, because the relaunch has no `--hidden`.
- If the installer fails to start asynchronously, lolPing still quits. That's electron-updater's design; the next launch offers the update again.
